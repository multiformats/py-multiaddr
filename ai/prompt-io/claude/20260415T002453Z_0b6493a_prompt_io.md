## Response summary

Add WireGuard (`wg`) as a new multiaddr protocol with draft code
`0x01C7` (an unassigned slot between `noise` 0x01C6 and `shs` 0x01C8
in the multicodec table). The codec handles 32-byte Curve25519 public
keys encoded as standard base64, matching `wg(8)` tooling conventions.
Example multiaddr: `/ip4/1.2.3.4/udp/51820/wg/<base64-pubkey>`.
